## Scoring Methodology

Technical score is an **MMR** (Elo-style, base 1500, uncapped) built from
continuous metrics, normalized onto a **0-1000 display scale** (500 = market-typical;
650+ recommended tier, <450 below threshold). Components, roughly by weight:

| Component | Driver |
|-----------|--------|
| Appreciation | URA rate vs 4%/yr baseline, confidence-weighted by transaction count |
| PSF value | Symmetric: discount vs URA market PSF adds, premium subtracts |
| Yield | Gross yield vs 3.2% baseline |
| Liquidity | Transaction volume, buyer pool, development size, price band |
| Future | Upcoming MRT, govt zones, transformation |
| Lease/Age | Continuous decay; 3-7yr age sweet spot |
| Red flags | West-facing, suspicious PSF, oversized/mismatched layout |

Missing data is neutral (0), never penalized. The technical score is one input —
the AI verdict above is the actual recommendation.
